# ECHO LOOP — App Review Notes Draft

ECHO LOOP is an offline-first neon arcade survival game. No account or login is required.

Review path:
1. Launch the app and complete/skip onboarding.
2. Tap PLAY to start a run. Drag to move; use DASH when available.
3. Previous movement recordings return as hostile echoes. Later stages introduce special echoes, arena events, hazards, and boss encounters.
4. The Shop contains two non-consumable StoreKit 2 products: Remove Ads and Premium Neon. Settings contains Restore Purchases.
5. A rewarded ad can optionally be used for one revive. No ad interaction is required to start or continue normal gameplay.
6. Game Center is used for leaderboard and achievements. The game remains playable if Game Center is unavailable.
7. Google UMP privacy choices are surfaced in Settings when required.

No reviewer login credentials are necessary.
