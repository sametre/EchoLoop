# ECHO LOOP — In-App Purchase Products

Create these in App Store Connect under Monetization → In-App Purchases before release.

| Product ID | Type | Reference name | Suggested purpose |
|---|---|---|---|
| `com.sameter.echoloop.removeads` | Non-Consumable | ECHO LOOP Remove Ads | Permanently removes banner/interstitial advertising and enables ad-free revive behavior defined by the app. |
| `com.sameter.echoloop.premiumneon` | Non-Consumable | ECHO LOOP Premium Neon | Unlocks the Premium Neon cosmetic entitlement. |

Do not change product IDs after creating them unless the code is updated too. Add localization, pricing, review screenshot, and review notes in App Store Connect. Because these are the app's first non-consumable products, include them with the first app-version submission for review.
