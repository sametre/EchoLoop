ECHO LOOP Support

Need help with gameplay, purchases, ads, Game Center, or restoring Premium Neon / Remove Ads?

Before contacting support

  • Update iOS and ECHO LOOP to the latest available versions.
  • Use Settings → Restore Purchases for previous non-consumable purchases.
  • Confirm Game Center is signed in if leaderboards or achievements are unavailable.
  • If an ad fails to load, continue the run or try again later; a purchase is never required to play.
